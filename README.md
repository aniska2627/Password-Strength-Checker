
# Password Strength Checker

## Project Description
A Python-based cybersecurity tool that evaluates password strength based on length, uppercase letters, lowercase letters, numbers, and special characters.

## Features
- Checks password length.
- Identifies uppercase and lowercase letters.
- Detects numeric characters.
- Checks special characters.
- Classifies passwords as Weak, Medium, or Strong.
- Provides suggestions to improve password security.

## Technologies Used
- Python 3
- Python IDLE
- String module

## How to Run
1. Download the Python file.
2. Open it using Python IDLE.
3. Press F5 to execute.
4. Enter a sample password.
5. View the strength and feedback.

## Objective
To demonstrate basic password security principles and Python programming concepts.
